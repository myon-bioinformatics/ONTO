# SNS攻略本の概念例（完全な架空例）

この教材は特定の投稿・会話・人物・案件からの引用ではなく、一般的な文章戦略を試すために新規作成した合成データである。実際の投稿の効果は未実測。実在するSNS利用者の観察結果でもない。

## 目標と戦略

- Goal: 短い文章を読みやすくする
- Context: 架空の短文投稿サービス
- Strategy: 対比、簡潔さ、オチ、語呂
- Constraint: 個人や居住地を推測させない、根拠のない断定を避ける
- Evaluation: 未実測（反応が増えるとの主張はしない）

架空の入力例：「自動販売機にお辞儀したら、先に商品が出てきた」。これはテキスト構造の動作例であり、現実の体験・引用・観測ではない。

## 匿名化と非再識別

元の私的な事例をマスキングして再利用するのではなく、**原文との対応を持たない独立した架空事例**を使う。固有名詞を消すだけでは、時系列・経歴・地名・交通・職種・所属・契約形態・独特な発言の組み合わせから人物や居住地域が推測され得る。ここではそのような属性を保存しない。原文、スクリーンショット、引用URL、アカウントID、正確な時刻、座標、IPアドレス、地域・タイムゾーン、組織・勤務情報、属性推定や隠れた対応表も保存しない。

このサンプルは完全な匿名性を形式的に証明するものではない。公開前には、他データとの突合を含めて目視点検する。

## 機構の分離

- ONTO: Goal / Context / Strategy / Constraint / Evaluation の語彙とグラフ整合性
- TaxOntOy: 戦略の階層分類（別途検討）
- TopOntoLogy: 関係・到達可能性・循環の分析（別途検討）
- OnTautoLogy: 有効性についての仮説・反例・判定（別途実測）
- Portfolio: 入力支援UI（将来の利用候補）

「面白い」「拡散する」は測定前に確定させない。評価は `unverified` とする。センシティブな話題を入力した場合は、属性の抽出・公開を避け、抽象的な手法だけ扱う。

