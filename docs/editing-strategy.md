# 添削攻略の判断規則（第2段階）

独立した合成教材のみを使用する。個人属性・地域・原文との対応情報は収集しない。

## 分解

目的、読者、文体、語彙、構文、情報構造、リズム、ユーモア、投稿構造、リスク、評価の11観点を分離する。観測→診断→操作選択→候補生成→評価の順に扱う。長所の維持も操作として扱う。

規則は特徴と条件から操作候補を選ぶ仮説であり、効果を保証しない。専門語は一般読者向けなら平易化、専門読者向けなら維持する反例を用意する。公開時の再識別リスクと根拠不足は効用の加点では相殺しない。公開可否は別途確認する。

[規則データ](../examples/social-strategy/editing-rules.json) は11規則と3つの独立した操作例を持つ。実際の反応は未実測。数値評価を実測として扱わない。

## 分担案

TaxOntOy: 特徴・操作の分類。TopOntoLogy: 操作の依存・競合。OnTautoLogy: 条件・反例・未知。ONTO: 共通グラフの検証。Portfolio: 将来の対話UI。各利用側への移植は既存語彙との照合後に行う。

## 検証

`python -S -m unittest discover -s tests -p 'test_editing_rules.py'`

この段階では特徴を人が指定する。自動意味解析・文章生成・SNS効果測定は実装しない。
